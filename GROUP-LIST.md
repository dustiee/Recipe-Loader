# Item Groups Reference

This file contains the list of built-in groups.

The format is:

**Group Name:** ```<groupName>```
- ```<InternalNames>```
- ```<OfItems>```
- ```<InThisGroup>```
- ``` . . . ```

When you specify an item slot with the group attribute like so:
```
<item group="something" ... />
```

Any item from the group will be valid for that slot. As long as other item slots using the same group have the same item. <br>
If you want item slots to be able to use any item from the group regardless of the items used in slots with the same group,
add the element ```<allowMixed />``` to your recipe.
